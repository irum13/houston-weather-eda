# Data

The original academic notebook scraped Wunderground daily history pages for Houston/KIAH.

For this reproducible portfolio rebuild, the project uses Open-Meteo's historical weather archive API for Houston/KIAH-area coordinates:

https://open-meteo.com/

Study window:

```text
2022-01-01 to 2023-01-31
```

The fetch script writes:

```text
data/raw/houston_hourly_weather_open_meteo_2022_2023.csv
```

Processed summary files are generated by:

```text
src/analyze_weather.py
```
